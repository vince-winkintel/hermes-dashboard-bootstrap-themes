# Attribution

This repository contains Hermes Agent dashboard theme YAML files created for the Hermes dashboard theme system.

## Bootswatch

The included themes are inspired by public Bootswatch Bootstrap 5 themes:

- [Bootswatch Slate](https://bootswatch.com/slate/)
- [Bootswatch Spacelab](https://bootswatch.com/spacelab/)

Bootswatch is created by Thomas Park and contributors and is available under the MIT License. Source distributions are available at:

- https://github.com/thomaspark/bootswatch/tree/v5/dist/slate
- https://github.com/thomaspark/bootswatch/tree/v5/dist/spacelab

This repository does not vendor full Bootswatch CSS. It maps public Bootstrap/Bootswatch color and component ideas into Hermes dashboard YAML theme definitions, with dashboard-specific CSS refinements for Hermes UI surfaces.
